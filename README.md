## 🎯 Featured Projects

### Gloomhunt — [Live](https://gloomhunt.onrender.com)
Built my own 2D game engine in vanilla JavaScript and HTML5 Canvas and used it to create and launch Gloomhunt, a competitive top-down shooter where players earn real money. Includes a payment and payout system, server-side anti-cheat that re-simulates gameplay to detect fraud, and a monitoring tool that detects frame drops and pinpoints the responsible subsystem. 50,000+ lines, 230+ automated tests.

**Tech:** Vanilla JavaScript, HTML5 Canvas, Node.js, Express, PostgreSQL, Vitest

### Street Keeper — [Live](https://street-keeper.onrender.com)
Running app that connects to Strava, tracks which streets you've completed, and suggests the nearest unfinished ones. GPS data matched against real street maps via PostGIS spatial queries. Two matching engine versions, improving accuracy from ~85% to 90% with zero false positives.

**Tech:** React 19, TypeScript, Node.js, Express, PostgreSQL, Prisma, pg-boss, Vitest, Strava API

### Kevvlar — [Live](https://kevvlar.com)
Project management SaaS with real-time chat, video meetings, file sharing, and kanban boards. Co-founded with a designer, I built the entire platform. ~150 users, 200+ workspaces, still live since 2021.

**Tech:** React, Redux, Node.js, Express, MongoDB, Redis, WebSockets, Twilio, Stripe, AWS

### [Hue Smash](https://github.com/devevangel/hue-smash)
Open-source collaborative web game I created to give fellow students hands-on experience with collaborative development. Led the project: defined scope, reviewed contributions, resolved merge conflicts, maintained code quality.

**Tech:** JavaScript, Canvas API, Git workflows

## 🔧 Hardware Projects

### 6-Axis Gyro Stabilisation Module
Designed and built a 6-axis IMU-based stabilisation module for real-time attitude correction in model rockets. Computes corrective outputs to counteract roll, pitch, and yaw deviations during flight. Functional prototype, bench tested.

### Project Sentinel — Autonomous UAV
Designed a fixed-wing UAV for security surveillance. Airframe modelling in Fusion 360 and SolidWorks, sensor payload planning, and research into autonomous navigation. Design stage.
